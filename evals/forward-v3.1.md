# Method repair and unfamiliar-data forward tests

The 3.1 series repairs defects found in saved native files and independently read pages. It changes the skills, rather than correcting a gallery image and calling that an execution improvement. No matched baseline or general quality, completion or speed advantage is established.

## Fixed procedure

Five gates were registered before outputs: source and reasoning, actual native formats, visual communication, reader comprehension and practical handoff. All applicable gates must pass; an unresolved material partial result fails the trial. Source preparation and the independent arithmetic oracle are separate from execution. Each executor starts without previous conversation history and receives only frozen source data, a neutral brief, the candidate methods and available runtime/format instructions. It does not receive old failures, evaluator answers, a preferred shortlist or a target layout.

The executor may inspect and revise its own work before its first completed handoff. The owner neither inspects drafts nor provides content coaching. The first completed handoff is sealed before assessment; no owner changes to the output or its rebuild code are allowed. A failed completed trial is retained, the methods are corrected and a different dataset is used next. There is no arbitrary authoring deadline. Logistics messages and actual interruptions remain distinct from quality evidence.

Source checks include visible pages, notes, native charts and embedded data, workbook values and formulas. Native files are opened with actual PowerPoint and Excel; PowerPoint exports are compared with the delivered PDF. Independent readers assess pixels and practical reuse separately. Model reader checks are proxies, not measured human comprehension or accepted taste. Proposed pilots do not establish approval, local readiness, adoption or intervention effects.

A separately drawn PDF did not establish correctness of the native presentation. The 3.1.0 repair made claim scope, missing values, shared computed facts, native category/data integrity, visible standalone definitions and readable action handoffs explicit.

The optional Office helper was added as a structural check. It discovers OOXML parts, reports full ordered category domains and missing numeric positions, and rejects malformed indices, unequal shared categories or cached Excel errors. Six parser controls pass; the original defective Melbourne presentation is rejected. Sparse bindings and unsupported chart types are reported as unverified. This helper cannot establish factual accuracy, visual craft or reader understanding.

## Candidate 3.1.1 repair

The methods now require explicit comparison references and derived component names/units, retain all plotted data while choosing a readable displayed tick cadence, mark important observations directly, organize series emphasis and keep color roles consistent. Action and source pages are organized around their reading task. Launch prerequisites distinguish completed evidence from the activity of checking it, while allowing conditional planning. A companion rebuild recipe includes actual commands, working directory, runtime configuration or discovery and a separate output location. No palette, slide count, chart count or dataset answer is prescribed.

An independent method review checked these instructions for scope and contradictions. Package structural checks and parser controls are separate from the next artifact evaluation.
