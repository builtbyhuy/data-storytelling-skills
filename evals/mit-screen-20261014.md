The earlier three-condition trial did not cover every potentially useful MIT repository. Current primary GitHub metadata, pinned method files and licenses were inspected before adding another condition. Stars are dated popularity observations, not certification, and a plotting engine is not an agent skill.

The additional visual-explainer condition uses its original pinned report subset: SKILL.md, style-guide.md, diagrams.md, page.html and the [MIT license](https://github.com/nicobailon/visual-explainer/blob/33a6b4d43958d2d152c9cb13762af802062fade5/LICENSE). No installation is required for this normal HTML path. The shared user brief governs offline assets, PDF pagination, SVG/data/rebuild outputs and numeric verification; the skill does not itself provide those complete handoffs. Its template's remote fonts must be handled within the same offline requirements as every other condition.

This is an untested gap in the earlier recorded comparisons, not evidence that a past search deliberately rejected better methods. Method inspection can justify a trial; only completed outputs and matching review can support a claim about their observed quality. See [the new-source comparison](solo-v3.3.md) for actual results and limits. Other candidates remain available for a suitable task; they are not declared inferior because this bounded trial does not run them.
