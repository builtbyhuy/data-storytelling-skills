# Working terminology

- **Data / information / insight / action:** recorded values; organized meaning; a supported interpretation relevant to a decision; a proposed or executed response. A useful insight need not be surprising.
- **Observation / hypothesis / estimate:** what the chosen data shows; a possible explanation; an assumption-dependent quantity. Keep these distinct in prose and charts.
- **Grain:** what one row/mark represents. Keys and denominators define which comparisons are meaningful.
- **Exploratory / explanatory:** discover and challenge patterns; communicate selected evidence for a particular reader. Explanation does not erase contradictory evidence.
- **BUS:** Big, Useful, Surprising. Weigh materiality and usefulness in context; surprise is a possible benefit, not a prerequisite or calibrated score.
- **TOSCAR:** Trouble, Owner, Success, Constraints, Actors, Reference. A compact way to frame a real decision.
- **ARC:** Setting/Hook, Rising evidence, Aha or main takeaway, Resolution. An optional argument arrangement after analysis.
- **4D:** Define the problem, Desired outcome, Do/actions, Data to measure. Outcome targets are not forecasts.
- **Cost of inaction:** a scenario requiring a base, horizon, recoverability and assumptions; it is not automatically the full observed loss.
- **Data-ink:** prioritize useful marks; preserve units, references, uncertainty and exceptions that make the chart interpretable.
- **Simpson's paradox:** an aggregate comparison can point in the opposite direction from within-group comparisons because composition differs. Assess the actual data rather than assuming every aggregate is misleading.
- **SSOT / semantic layer:** source authority and shared metric meaning. These responsibilities can be covered by a local file and agreed definitions for a small task.
- **Orchestration:** selecting and sequencing needed work using available tools. A method description is not an execution hook, service or account permission.
